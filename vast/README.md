# `vast/` &mdash; Vast.ai lifecycle scripts

The cloud-build control plane. Drives one Vast.ai instance through its full
lifecycle: search &rarr; provision &rarr; sync &rarr; build &rarr; fetch &rarr; destroy.

## Prereqs

- `pipx install vastai` (CLI v1.0.7+ tested)
- A Vast.ai account with a funded balance and an API key in `vast_api_key`
  (repo root, gitignored).
- An SSH keypair at `~/.ssh/id_ed25519_vastai` (auto-generated by
  `provision.sh` on first run).
- `rsync`, `ssh`, `scp` on `PATH` (Linux / WSL2 / macOS).

## Scripts

| Script | What it does |
|---|---|
| `search.sh` | Print top N rentable offers matching the AOSP build profile (>=32 vCPU / >=64 G RAM / >=1 TB disk / <=$0.80/hr). |
| `provision.sh <offer_id>` | Rent a chosen offer, attach our pubkey, wait for SSH, save instance id to `.instance_id`. |
| `ssh.sh [cmd...]` | SSH into the active instance (interactive or one-shot). |
| `sync-source.sh` | `rsync` this repo to `/workspace/android-oem-pipeline` on the instance. |
| `kick-build.sh` | Install Docker (if missing), build our Dockerfile on the remote, run the AOSP build container, stream logs. |
| `fetch-artifacts.sh` | Pull `out/*` (img zip + `cvd-host_package.tar.gz` + `SHA256SUMS`) back to `out/<timestamp>/`. |
| `destroy.sh [--destroy|--stop]` | Stop billing. `--destroy` (default) wipes the instance; `--stop` keeps disk for resume. |
| `common.sh` | Shared helpers (auth, ssh wrapper, scp wrapper). Sourced by the others. |

## End-to-end run

```bash
./vast/search.sh
./vast/provision.sh 12345678   # offer id from search output
./vast/sync-source.sh
./vast/kick-build.sh           # ~5-7h cold, ~30-60min warm
./vast/fetch-artifacts.sh
./vast/destroy.sh
```

## Cost guardrails

- `search.sh` filters by `DPH_MAX=0.80` (~$0.80/hr cap). Override:
  ```bash
  DPH_MAX=0.50 ./vast/search.sh   # tighter cap
  ```
- A cold build at $0.40/hr is roughly $2.50 end-to-end (sync + build + fetch).
  See [`docs/vast-runbook.md`](../docs/vast-runbook.md).
- Always run `./vast/destroy.sh` when you're done. Stopped instances still
  bill for disk (~$0.05-0.10/hr).
